# NextStep CV (Not Finished)

Desktop application designed to create professional resumes quickly, easily, and completely offline.

Originally conceived as a modern web application built with React, Vite, TypeScript, and a Flask/Python backend for data handling and PDF generation with WeasyPrint, the project now evolves into a much more accessible and straightforward solution for end users.

The new version of NextStep CV removes the need for servers, deployments, or complex configurations, transforming it into a desktop application powered by Electron that runs entirely locally. All processing, CV editing, and PDF generation take place directly on the user's device.

---

## ⭐ Main Features

- Modern, fast interface  
- Runs as a desktop application thanks to Electron  
- 100% offline: does not require any Internet connection  
- No backend or external dependencies: all logic and processing occur locally  
- Built-in PDF generation without relying on remote services  
- Clean and intuitive design, ideal for users who want to create their CV in minutes  
- Easy distribution through installers for Windows, macOS, and Linux  

---

## 🎯 Current Project Focus

The goal of this new direction is to offer a fully autonomous and accessible tool, avoiding the technical complexity of deploying a web application with a backend.  
NextStep CV becomes a ready-to-use solution, ideal for any type of user regardless of their technical expertise.

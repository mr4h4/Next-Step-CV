NextStepCV v2 BETA

Desktop application designed to create professional resumes quickly, easily, and completely offline. Originally conceived as a modern web application built with React, Vite, TypeScript, and a Flask/Python backend for data handling and PDF generation with WeasyPrint, the project now evolves into a much more accessible and straightforward solution for end users. The new version of NextStep CV removes the need for servers, deployments, or complex configurations, transforming it into a desktop application powered by Electron that runs entirely locally. All processing, CV editing, and PDF generation take place directly on the user's device.

The goal of this new direction is to offer a fully autonomous and accessible tool, avoiding the technical complexity of deploying a web application with a backend. NextStep CV becomes a ready-to-use solution, ideal for any type of user regardless of their technical expertise.

Cómo funciona XML y cómo ayuda a rellenar plantillas de currículums

XML (eXtensible Markup Language) es un formato de datos estructurado que permite almacenar información en etiquetas. Al separar datos (XML) y presentación (XSL/CSS/HTML) podemos mantener plantillas reutilizables y generar múltiples CVs a partir de la misma plantilla.

Flujo típico: un archivo XML contiene los datos del candidato; una plantilla XSL transforma esos datos en HTML presentable. Esto permite mantener varias plantillas (estilos) y el mismo conjunto de datos.
